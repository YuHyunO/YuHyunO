📍서울에서 활동하는 백엔드 개발자입니다.

주로 **Java**를 사용하며, 스케줄러, 서비스 로직 처리, SAP 연동 등 엔터프라이즈 시스템 개발에 관심이 많습니다.  
최근에는 TypeScript와 Drizzle ORM 같은 기술도 공부하고 있습니다.
------

## 🔧 주요 기술 스택
- **Java** (Spring, Quartz 등)
- **TypeScript** / Node.js
- ORM (Drizzle ORM 등)
- Linux & AWS 기본 지식
